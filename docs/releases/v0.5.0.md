Works with Posse 0.11.0 (formerly Mayor); the Mayor name is no longer recognized (D196, D292).

## What changed

- **`share.audience` values `mayor` and `mayor-world-group` are now `posse` and `posse-world-group`.** The old values are unknown, and an unknown value turns sharing off with a console warning. A server that has `mayor` set shares nothing until its config is edited. Nothing widens.
- **Posse 0.11.0 or newer is required for the two Posse modes.** With no Posse, or an older one, sharing is off in those modes and the console says why. The older-version check now refuses any Posse before 0.11.0, which cannot exist, so in practice it means "install Posse".
- **No old key is read.** A config with no `share.audience` is off, and the pre-0.4.0 keys (`share.enabled`, `share.candidates` and `share.require-mayor`) are ignored, so an old file can't switch sharing on. Posse is also now an optional load-before dependency in `paper-plugin.yml`.
- The shipped `config.yml`, the README, the console messages and the live test (`posse.js`, run with `BMM_POSSE_JAR`) use the new name.

## Upgrading from 0.4.1

A config that still has only the old keys has sharing off. Before the first start, change `share.audience: mayor` to `posse` and `mayor-world-group` to `posse-world-group` in `plugins/BlueMapMini/config.yml`. Install Posse 0.11.0 in the same stop. Nothing else changes.
